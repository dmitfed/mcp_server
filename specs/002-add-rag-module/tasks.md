# Задачи реализации — офлайн-модуль RAG для MCP-сервера

**Входные документы** [Спецификация](spec.md), [план](plan.md), [исследование](research.md), [модель данных](data-model.md), [контракт MCP](contracts/rag-tools.md), [манифест](contracts/rag-module.json), [приёмка](quickstart.md), [конституция](../../.specify/memory/constitution.md).

**Порядок** Пути в задачах отсчитываются от корня репозитория. `[P]` отмечает работу на разных файлах, которую можно вести одновременно после указанных зависимостей. Тестовые задачи покрывают проверки, заданные спецификацией, планом и протоколом приёмки. Сначала подготовьте проверки сценария и подтвердите, что они обнаруживают отсутствие требуемого поведения, затем реализуйте сценарий. Для ранних проверок используйте подготовленные материалы и ожидаемые ответы зависимостей. Реальные Qdrant, SQLite и модели обязательны там, где они указаны в задаче.

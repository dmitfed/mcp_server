# Проверка качества спецификации — офлайн-модуль RAG

**Дата** 2026-11-22

**Спецификация** [Офлайн-модуль RAG](../spec.md)

## Содержание

- [x] Заполнены сценарии с независимыми проверками, требования, сущности и критерии успеха.
- [x] Сценарии привязаны к задачам оператора и пользователя MCP-хоста.
- [x] Технологии в требованиях ограничены заданными хранилищами, форматами, структурным разбором кода и действующим контрактом проекта. Выбор конкретных парсеров, грамматик, моделей и схемы вызовов относится к техническому плану.
- [x] Критерии успеха измеряют наблюдаемые результаты индексации, поиска и чтения.

## Полнота требований

- [x] Приёмка извлечения покрывает Word и MathType, эталонные таблицы и формулы PDF, гибридный OCR и сверку описаний с источником.
- [x] Для исходного кода проверяются границы фрагментов, метаданные символов, верхнеуровневый код и ошибки синтаксического анализа.
- [x] Для поиска определены отбор активных версий до ограничения пула, содержимое кандидатов и порог реранкинга.
- [x] Зафиксированы результаты полной и частичной обработки, повтор после частичной обработки и изменения связанных ресурсов Markdown.
- [x] Описаны таймауты по обе стороны публикации, конкуренция снимков и перестроение индекса из SQLite.
- [x] Уточнены четыре сочетания прав, клиентские ошибки MCP v1 и локальная диагностика оператора.
- [x] Офлайн-приёмка проверяет передачу результата MCP-вызова обратно локальной генеративной модели.
- [x] Указано, какие решения принимаются в техническом плане. Открытых вопросов, блокирующих планирование, нет.

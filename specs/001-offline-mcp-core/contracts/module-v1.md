# Контракт модуля v1

[Запуск и доступ](server-mcp.md) · [Модель данных](../data-model.md)

Модуль распространяется как локально устанавливаемый Python-пакет или часть
локального пакета. Оператор явно указывает путь к JSON-манифесту в TOML.
Манифест и пакет готовятся до переноса на целевую машину.

```json
{
  "contract_version": 1,
  "module_id": "demo",
  "tools": [
    {
      "name": "demo_echo",
      "description": "Return the supplied text in the echo field.",
      "handler": "mcp_offline_core.demo:echo",
      "input_schema": {
        "type": "object",
        "properties": { "text": { "type": "string", "minLength": 1, "maxLength": 128 } },
        "required": ["text"],
        "additionalProperties": false
      }
    }
  ]
}
```

## Регистрация

- `module_id` — уникальный непустой идентификатор модуля. Имена инструментов
  глобально уникальны, включая отключённые инструменты. Они содержат от 1 до 128
  букв ASCII, цифр, точек, дефисов или подчёркиваний.
- `description` — непустое описание. `handler` содержит импортируемый
  Python-модуль и имя функции в формате `package.module:function`.
- `input_schema` — JSON Schema Draft 2020-12 с корнем `object`. Разрешены ссылки
  внутри этого документа. Внешняя ссылка или ошибочная схема отклоняется при
  старте. Регистрация манифеста не требует импорта обработчика.

## Вызов

Синхронная функция принимает два параметра в порядке `arguments, context`.
Первый — проверенный объект аргументов. Второй — контекст с неизменяемым
множеством `grants`, созданным ядром. Модуль проверяет требуемое полномочие
до выдачи защищённых данных или выполнения защищённой операции. Для отказа
модуль использует `PermissionError`, отображаемый в `permission_denied`.

Успешный результат — JSON-объект с конечными значениями. Для `demo_echo`
при аргументах `{"text":"mcp-check-001"}` это `{"echo":"mcp-check-001"}`.
Произвольное исключение переводится в `handler_error`. Вызов может быть прерван
по дедлайну, поэтому длительные операции должны учитывать частичное выполнение.
Модуль работает с правами пользователя сервера. Процессная граница служит
управлению временем и сбоями. Оператор подключает доверенный код.

Опубликованные поля, сигнатура и семантика v1 сохраняются при совместимых
изменениях. Для несовместимого изменения требуется новая версия контракта
и описание миграции согласно [конституции](../../../.specify/memory/constitution.md).
